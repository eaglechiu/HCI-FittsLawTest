Scenario definition
This prototype represents an interactive monitoring map. Each trial contains one cyan target marker and a random 1–5 gray distractor markers. The participant selects the marker whose color differs from the others.
The target center is placed exactly one assigned movement distance A from the previous target center. Current A levels are 280 and 520 px. R is the common circumradius of every marker shown in that trial, with levels 30, 50, and 70 px. The target shape is the experimental Shape condition; distractor shapes are randomized and may match the target shape.
Marker overlap is prevented. Target color, distractor color, map background, marker stroke, and visual styling are held constant. Star / Rounded Star and Triangle / Rounded Triangle preserve the incoming-tip orientation rule. Each condition contains six recorded movements using the fixed six-direction set 0°, 60°, 120°, 180°, 240°, 300°, exactly once each. Direction order is controlled in opposite pairs so every movement remains exactly A while the path stays inside the map.
